# 使用個案描述：[UC07] 手動遠端觸發灌溉

**使用個案名稱：** [UC07] 手動遠端觸發灌溉

**行為者：** 使用者

**目標：** 使用者可以遠端選擇盆栽，使系統傳送指令給裝置進行灌溉。

**前提：** 1. 使用者已登入系統。

**結束狀態：** 裝置完成灌溉，回傳成功訊息給系統並顯示。

**一系列事件：**

**正常程序：**

1. **選擇盆栽**：使用者選擇想灌溉的盆栽。
2. **系統檢查**：
    * 確認裝置是否與系統連線成功。
    * 確認水箱是否低於最低灌溉水量。
    * 確認土壤濕度是否需要灌溉。
3. **顯示狀態**：系統顯示該盆栽的土壤溫濕度以及是否建議灌溉。
4. **確認灌溉**：使用者按下按鈕確定灌溉，系統彈窗二次確認使用者是否灌溉。
5. **發送指令**：系統使用計算好的用水量傳送指令使裝置灌溉。
6. **回報結果**：裝置灌溉完會回傳成功訊息給系統，並且呈現給使用者。

**替代程序：**

1. **取消操作**：使用者在該頁面按下返回，退回主介面。

**例外路徑：**

1. **土壤不需灌溉**：若系統在 步驟 2 判斷不需要灌溉，並在 步驟 3 顯示不建議。若使用者仍在 步驟 4 執行灌溉，系統彈出警告，使用者可選擇忽略並以預設安全水量強制執行。
2. **無法取得感測數據**：若系統未收到訊息，步驟 3 顯示 N/A；步驟 4 會顯示「警告無法取得土壤濕度訊息」，使用者可選擇忽略警告並以預設安全水量執行。
3. **水箱缺水**：若系統在步驟 2 判斷缺水，彈出視窗顯示「請為水箱補水」，停留在當前頁面等待返回主頁或重試。
4. **連線失敗**：若系統在步驟 2 判斷遠端連線失敗，彈出視窗顯示「系統連接失敗，請檢查裝置連線」，停留在當前頁面等待返回主頁或重試。
5. **裝置回應逾時**：若系統在步驟 5 後十秒未收到成功訊息，顯示「裝置逾時，請檢查裝置是否運作正常」，停止等待並留在當前頁面。
