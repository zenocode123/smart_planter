# 使用個案描述：[UC07] 手動遠端觸發灌溉

**使用個案名稱：** [UC07] 手動遠端觸發灌溉

**行為者：** 使用者

**目標：** 使用者可以遠端選擇盆栽，使系統傳送指令給裝置進行灌溉。

**前提：** 1. 使用者在UC05選擇完盆栽，進入盆栽數據頁面。

**結束狀態：** 裝置完成灌溉，回傳成功訊息給系統並顯示。

**一系列事件：**

**正常程序：**

1. **灌溉觸發**：使用者按下灌溉按鈕。
2. **系統依次檢查**：
    * 確認水箱是否低於最低灌溉水量。 
    * 確認是否取得土壤溫溼度資訊。
    * 確認土壤濕度是否需要灌溉。
3. **確認灌溉**：使用者按下按鈕確定灌溉，系統彈窗二次確認使用者是否灌溉。
4. **發送指令**：系統使用計算好的用水量傳送指令使裝置灌溉。
5. **回報結果**：裝置灌溉完會回傳成功訊息給系統，並且呈現給使用者。

**替代程序：**

1. **取消操作**：使用者在該頁面按下返回，退回主介面。

**例外路徑：**

1. **土壤不需灌溉**：若系統在 步驟 2 判斷不需要灌溉，並在 步驟 3 顯示不建議，使用者可選擇忽略並以預設安全水量強制執行。
2. **無法取得感測數據**：若系統在步驟 2 未收到訊息，步驟 3 會顯示「警告無法取得土壤濕度訊息」，使用者可選擇忽略警告並以預設安全水量執行。
3. **水箱缺水**：若系統在步驟 2 判斷缺水，彈窗顯示「請為水箱補水」，等待使用者關閉彈窗。
4. **裝置回應逾時**：若系統在步驟 4 後十秒未收到成功訊息，彈窗顯示「裝置逾時，請檢查裝置是否運作正常」，停止計時器並等待使用者關閉彈窗。
