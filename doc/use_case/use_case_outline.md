# Use Case 大綱

## 1. 帳戶與裝置管理 (Account & Device)

- [UC01] 使用者註冊與登入
- [UC02] 綁定新盆栽裝置 (透過 Device ID/QR Code)
- [UC03] 設定植物檔案（品種、名稱）

## 2. 多盆栽監控看板 (Dashboard)

- [UC04] 檢視所有植物健康概覽 (列表模式)
- [UC05] 查看特定植物詳細數據 (溫濕度、光照、土壤濕度)
- [UC06] 查看植物最新照片與歷史紀錄

## 3. 遠端控制與 AI 互動 (Interaction)

- [UC07] 手動遠端觸發灌溉
- [UC08] 與植物 AI 進行對話互動
- [UC09] 修改自動偵測排程時間

## 4. 系統自動化案例 (System Automated Use Cases)

- [UC10] 定時執行偵測、拍照與 AI 分析（如你流程圖所示）
- [UC11] 自動發送每日健康報告 Email
