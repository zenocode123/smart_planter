# 使用個案描述：[UC01] 系統初始化與登入

**使用個案名稱：** [UC01] 系統初始化與登入

**行為者：** 使用者

**目標：** 
1. 在裝置首次啟用時，設定管理員帳號與密碼。
2. 在日常使用時，透過密碼驗證登入系統以取得控制權。

**前提：** 
1. 裝置已開機並連上網路。
2. 使用者透過瀏覽器存取裝置 IP。

**結束狀態：** 使用者成功進入系統主畫面（Dashboard）。

**一系列事件：**

**正常程序－（A）首次初始化 (First Boot)：**

1. **偵測狀態**：系統偵測到資料庫中無任何使用者，自動進入「初始化設定精靈」。
2. **設定管理員**：系統提示使用者設定：
    * **管理員名稱** (Username)
    * **登入密碼** (Password)
    * **確認密碼**
3. **提交設定**：使用者送出表單。
4. **系統建立**：系統將密碼雜湊 (Hash) 後寫入本地資料庫。
5. **自動登入**：初始化完成後，系統自動將使用者視為已登入，並導向主畫面。

**正常程序－（B）日常登入：**

1. **進入首頁**：使用者瀏覽裝置首頁，因未登入被導向至登入頁面。
2. **輸入憑證**：使用者輸入管理員名稱與密碼。
3. **驗證憑證**：系統比對資料庫中的雜湊密碼。
4. **建立工作階段**：驗證成功，系統建立 Session 或發放 Token。
5. **進入系統**：跳轉至儀表板 (Dashboard)。

**替代程序：**

1. **記住我 (Remember Me)**：使用者在登入時勾選「記住我」，系統設定較長效期的 Cookie，下次開啟瀏覽器無須重新登入。

**例外路徑：**

1. **密碼錯誤**：系統顯示「帳號或密碼錯誤」，並保留在登入頁。
2. **遺失密碼 (硬體重置)**：
    * 因系統為本地端運作，無 Email 伺服器可發送重設信。
    * 若使用者忘記密碼，需透過**實體操作**（如：SSH 連入樹莓派刪除特定 DB 檔案，或長按實體重置鈕若有設計）來觸發「恢復原廠設定」或「重置密碼流程」。
