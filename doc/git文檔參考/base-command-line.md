# Command line

## 基本

**📚 參考資料:**

- [Command line crash course](https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Command_line)

### 列出當前目錄的檔案和資料夾

`ls`（list）

### 顯示當前所在目錄的完整路徑

`pwd`（print working directory）

### 切換目錄

`cd`（Change Directory）

### 查看指令使用手冊

`man`（Manual）

### 建立目錄

`mkdir`

### 建立檔案

`touch`

### 複製檔案或目錄

`cp`

### 移動檔案或目錄

`mv`

### 刪除檔案或目錄

`rm`

### 下載檔案可於特定網址找到

`curl`

### 開啟檔案

`open`

### 頁面清空

`clear`
