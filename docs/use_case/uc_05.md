# 使用個案描述：[UC05] 查看特定植物詳細數據

**使用個案名稱：** [UC05] 查看特定植物詳細數據（溫濕度、光照、土壤濕度）

**行為者：** 使用者

**目標：** 使用者在主介面選擇特定盆栽，查看該盆栽詳細數據（溫溼度、光照與土壤濕度）。

**前提：** 使用者已登入系統。

**結束狀態：** 使用者查看完畢。

**一系列事件：**

**正常程序：**

1. **選擇盆栽**：使用者在主介面選擇特定盆栽。
2. **確認連線**：系統確認是否與裝置連線。
3. **數據請求**：系統向裝置請求最新的感測數據，並確認數據無異常。
4. **顯示數據**：系統顯示該盆栽詳細數據（溫溼度、光照與土壤濕度）。

**替代程序：**

1. **返回主頁**：使用者在該頁面按下返回，退回主介面。
2. **手動刷新數據**：使用者點擊「刷新」按鈕，系統重新執行 「正常程序」的步驟 2（確認連線）。

**例外路徑：**

1. **感測數據缺失**：若系統在步驟 3 沒有接收到感測器訊息，相關欄位會顯示「N/A」。
2. **裝置連線中斷**：若系統在步驟 2 無法連線到裝置，彈出視窗顯示「與裝置失去連線，請檢查」，等待使用者關閉彈窗或重試。
