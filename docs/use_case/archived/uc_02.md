# [DEPRECATED] 使用個案描述：[UC02] 新增鄰近盆栽連結 (Add Peer Device)

> **注意：** 此功能在專案初期開發階段暫不實作，優先專注於單機功能開發。

**使用個案名稱：** [UC02] 新增鄰近盆栽連結 (Add Peer Device)

**行為者：** 使用者

**目標：** 使用者可在當前盆栽的操作介面中，加入其他盆栽（Peer Device）的連結資訊（IP 位址或網域名稱），以便在側邊欄快速切換管理多個盆栽。

**前提：** 
1. 使用者已登入系統。
2. 欲加入的目標盆栽裝置已開機並連上區域網路。
3. 使用者知曉目標裝置的 IP 位址（可透過機身 QR Code 貼紙掃描獲取）。

**結束狀態：** 側邊欄或裝置列表新增了目標盆栽的連結，點擊後可跳轉至該裝置的控制頁面。

**一系列事件：**

**正常程序：**

1. **進入設定頁面**：使用者點選「新增盆栽連結」或「鄰居盆栽管理」。
2. **輸入資訊**：使用者輸入目標盆栽的資訊：
    * **顯示名稱**（例如：客廳的龜背芋）。
    * **連線位址**（IP Address 或 Hostname，例如 `192.168.1.105` 或 `http://planter-livingroom.local`）。
3. **連線測試**：使用者點選「測試連線」。
    * 系統後端嘗試對目標位址發送 Ping 或 HTTP GET 請求（例如 `/api/health`）。
4. **確認新增**：
    * 若測試成功，系統顯示目標裝置的回應資訊（如裝置名稱、在線狀態）。
    * 使用者按下「確認新增」。
5. **儲存連結**：系統將該筆連結資訊存入本地資料庫（Peer Device List）。
6. **更新介面**：側邊欄即時更新，顯示新加入的盆栽捷徑。

**替代程序：**

1. **掃描 QR Code 取得 IP**：
    * 若使用者使用手機瀏覽，可點選「掃描 QR Code」。
    * 瀏覽器請求相機權限，使用者掃描目標盆栽機身上的貼紙。
    * 系統自動填入解析出的 IP 位址或網址至輸入框（回到步驟 2）。

**例外路徑：**

1. **連線測試失敗**：
    * 若步驟 3 測試無法連線（目標關機、IP 錯誤、不同網段），系統顯示紅色錯誤訊息「無法連線至該裝置，請檢查 IP 或網路狀態」。
    * 使用者可選擇「放棄」或「強制儲存」（標記為離線裝置）。
2. **格式錯誤**：若輸入的 IP 格式不正確，前端即時提示錯誤。
