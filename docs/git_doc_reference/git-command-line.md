# git 指令

## 常用

### status

```zsh
git status
```

### add

```zsh
git add .
```

### commit

```zsh
git commit -m "提交訊息"
```

```zsh
git commit --amend
```

```zsh
git commit -a -m "提交訊息"
```

### branch

```zsh
git branch 分支名
```

```zsh
git branch -d 分支名
```

```zsh
git branch -m '新分支名'
```

### switch

```zsh
git switch 分支名
```

```zsh
git switch -c 分支名
```
